# Contributing

Thanks for your interest in contributing to Social Poster Agent.

## How to Contribute

1. Open an issue to discuss significant changes before writing code.
2. Fork the repository and create a branch for your change.
3. Keep changes focused and covered by tests where possible.
4. Run `pnpm lint` and `pnpm test` before submitting.
5. Open a pull request with a clear description and reference any related issues.

## Code Style

- Follow the existing project structure and naming.
- Prefer explicit, simple code over clever abstractions.
- Do not hardcode secrets or project-specific branding.
