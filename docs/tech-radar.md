## A. Выводы аудита (M0.4)

### A-1. LangGraph 0.2 → 1.x — миграция выполнена, риск остался в рантайме
Код графа компилируется и юнит-тесты зелёные, но семантические различия 1.x
(interrupt/resume, сериализация чекпоинтов, `Command`) проявляются только под нагрузкой.
**Действие:** до GATE M3-M4 обязателен soak генерации на 1.x в staging с resume-сценариями
(падение mid-graph → resume из Redis-чекпоинта). `RedisCheckpointSaver` проверить против
нового пакета `@langchain/langgraph-checkpoint`.

### A-2. Zod 3 → 4 — Adopt
Компиляция и тесты зелёные. При касании валидационного кода помнить о переименованных API
(`.issues`, изменённые coercion-правила). Новой миграционной работы не требуется.

### A-3. Prisma 6 → 7 — Adopt c оговоркой
Генератор переключён на новый `prisma-client` (output `src/generated/prisma`,
moduleFormat cjs). SQL-миграции не затронуты. **Действие:** убедиться, что деплой-скрипты
и Dockerfile прогоняют `prisma generate` ДО сборки (новый output внутри src влияет на
tsc-порядок). Миграция `20260822000000_add_post_link_attribution` применить при ближайшем
`prisma migrate deploy` (GATE M0).

### A-4. TypeScript 7.0.2 — наблюдение
Мажорный скачок; компиляция проходит. Держать в уме при апгрейде тулов (типизированные
enters/exits в ts7 могли изменить поведение strict-флагов).

### A-5. playwright-core 1.60 + coreBundle-патч — устойчиво
`patch-playwright.js` нашёл все три сайта патча («Already patched»). Правило из AGENTS.md
остаётся: после каждого апгрейда playwright-core перезапускать скрипт и сверять сайты.

## Процессные риски (наблюдение от 2026-08-22)

Зафиксированы гонки между параллельными агентскими сессиями в одном рабочем дереве:

- коммит `e85ec78` поглотил чужие незакоммиченные правки через `git add -A`
- в `my_zodiac_ai` HEAD и индекс менялись во время коммитов (несколько неудачных попыток)

**Рекомендации:**
1. Агентским сессиям — работать в отдельных worktree (`git worktree add`), а не в одном дереве
2. Запретить `git add -A`/`git commit -a` в автоматических сессиях; только явные пути
3. Перед мегакоммитом — `git stash list` + проверка `git status` на чужие незакоммиченные файлы
