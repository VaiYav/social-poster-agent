# 08 — Backlog: оценки, порядок, что разблокирует что

**Единый источник истины для взятия в работу.** Сводный план: changeset-гигиена из код-ревью (`06`) +
7 архитектурных пунктов (`01·E`) + баги из `02` по severity + находки max-review текущих изменений
(`07`) + до-делка фич и снятие заглушек. Путь —
**stealth по всем сетям**; API только бесплатный **read** для метрик (`05`).

## Легенда усилий (один разработчик, грубо)
- **S** ≤ 0.5 дня · **M** 1–2 дня · **L** 3–5 дней · **XL** > 1 недели.
- Оценки грубые: точность снижают god-объекты (`01 A6`) и **отсутствие E2E против реального DOM**
  (`01 D1`) — фиксы постинга/селекторов нужно валидировать `dry-run`-ом вручную.

## Майлстоуны
- **M0.0 — Changeset hygiene & commit split** (разложить блоб на коммиты, убрать артефакты из
  трекинга, миграции одним коммитом). Раздел 0. ~0.5–1 день.
- **M0 — Безопасность/быстрые криты** (снять «постим мусор/дубли», закрыть дыры). ~3–4 дня.
- **M1 — Exactly-once + агентская отправка безопасна** (предусловие для «агент сам принимает/
  валидирует/отправляет»). ~1.5–2 недели.
- **M2 — Архитектурный фундамент** (7 пунктов, ports, split, CI E2E). ~3–4 недели.
- **M3 — Полные фичи / снятие заглушек** (recycling, metrics, engagement, replies, quote-cards,
  trending). ~3–5 недель.

> Жёсткое правило: **автономную отправку (`AUTO_APPROVE`/runner) НЕ включать до конца M1.** Сейчас
> активный путь авто-аппрува валидацию обходит и при отсутствии score постит «на всякий» (`02 AU1/AU2`).
> Вдобавок (`07` BUG-1): пост-сейв simhash-дедуп реджектит **100%** сгенерированного — без фикса
> автономия не публикует ничего даже после включения. Чинить в M0.

## 4. Предлагаемый порядок исполнения (спринты)

**Спринт 0 (M0.0, ~0.5–1 день):** CR-1…CR-7 — разложить блоб на коммиты, убрать артефакт из трекинга,
миграции одним коммитом, автономные модули за флагом OFF. Раздел 0.

**Спринт 1 (M0, ~неделя):** RC1, R1, AU2, AU1, AU3, SEC1, B5/SEC4, PO1, P7, A2; + (`07`) BUG-1, SEC-2,
BUG-5, BUG-7, BUG-8, BUG-11.
→ Результат: безопасные быстрые криты закрыты; флаги корректны; авто-отправка пока выключена, но gate
уже fail-closed.

**Спринт 2–3 (M1, ~2 недели):** P1, P2, P3/P4, reaper stuck-POSTING, A4 (+in-run дедуп), SEC2, RP1;
+ (`07`) BUG-6, BUG-9, BUG-12.
→ Результат: **exactly-once и проверяемая публикация** — можно включать «preview/dry» автономии, затем
осторожно реальную отправку.

**Спринт 4–6 (M2, ~3–4 недели):** A5, A3, D1 (CI E2E), SEC3, SE1, SEC6, затем A6 (разнос god-объектов).
→ Результат: фундамент под рост; регрессии селекторов ловятся CI.

**Спринт 7+ (M3, ~3–5 недель):** metrics-scraper → recycling/hook-bank, engagement, replies,
quote-cards, trending; добивание Medium/Low по модулям.
→ Результат: заглушек нет, фичи полные.
