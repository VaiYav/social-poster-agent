## Feature status rules

- `IN_PROGRESS` reflects an active owned workstream, not percentage complete.
- `VERIFY` is deliberately used where docs and source disagree or a referenced
  decision/evidence artifact is missing.
- Optional expansion does not reopen a completed feature; create a new feature/task.
- Roadmap milestones derive from this table, not the other way around.
